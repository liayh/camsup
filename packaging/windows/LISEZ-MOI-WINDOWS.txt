CamSup - fabriquer puis installer sur un PC Windows 10/11 (64 bits)
===================================================================

1. Installer, une seule fois :
   - Python 3.12 : https://www.python.org/downloads/windows/
     (pendant l'installation, cocher « Add python.exe to PATH »)
   - Inno Setup 6 : https://jrsoftware.org/isdl.php
   Node.js n'est pas nécessaire : l'interface est déjà compilée dans ce dossier.

2. Fabriquer l'installateur : clic droit sur le menu Démarrer > « Terminal » (ou PowerShell), puis :
     cd CHEMIN\VERS\camsup
     powershell -ExecutionPolicy Bypass -File packaging\windows\build.ps1
   Durée : quelques minutes (téléchargement de PyInstaller et de ffmpeg, connexion Internet nécessaire).
   Résultat : dist\CamSup-Installation-1.0.0.exe

3. Installer : double-clic sur dist\CamSup-Installation-1.0.0.exe (droits administrateur).
   - Choisir le mot de passe du compte « admin » (10 caractères au moins, sans # ni guillemets).
   - Cocher « Démarrer CamSup maintenant ».

4. Utiliser : icône « CamSup » (menu Démarrer ou bureau) -> le navigateur ouvre http://localhost:8080
   - Se connecter : admin + le mot de passe choisi.
   - Enregistreurs et caméras > « Ajouter un enregistreur » : adresse IP du NVR (n'importe laquelle, le PC doit
     être sur le même réseau), utilisateur et mot de passe du NVR > « Se connecter au NVR » > « Toutes » > Ajouter.
   - Paramètres > e-mail de l'installateur.

Le logiciel démarre vide (aucune pharmacie, aucune caméra). Ses données sont dans C:\ProgramData\CamSup
(à sauvegarder : C:\ProgramData\CamSup\data\secret.key). Journaux : C:\ProgramData\CamSup\data\logs.
Désinstaller : Paramètres Windows > Applications > CamSup (les données de C:\ProgramData\CamSup restent ;
les supprimer à la main pour repartir de zéro).
